# Mental Vendas

CRM de vendas com painel, mentalidade, clientes, lembretes, foco do dia e Modo Calma.

## Arquivos
- `index.html` - estrutura da aplicação e carregamento das dependências CDN.
- `styles.css` - estilos visuais e responsivos.
- `app.js` - lógica React e funcionalidades da aplicação.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `styles.css` e `app.js` para a raiz do repositório.
3. Em **Settings > Pages**, selecione a branch principal e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

A aplicação continua usando React 18, Tailwind CDN e SheetJS CDN, então não é necessário instalar Node ou fazer build para esta versão.
